# Stage 4 — M4 3/6/12/24시간 완료 보고

**2023년 Validation 중간 결과**입니다. M1~M3 모델·결과를 보존했고 2024 Test 및 후속 모델·분석은 실행하지 않았습니다.

**핵심 결과:** M4는 persistence 대비 네 Horizon 모두 공식 개선 조건을 충족합니다. 그러나 M4의 RMSE 점 추정은 모든 Horizon에서 M3보다 높으며, **M4 vs M3의 공식 개선 조건은 모두 미충족**입니다. 설정·Feature·결측 처리를 결과에 맞춰 변경하지 않았습니다.

## 3. Feature·시간 정렬·결측·누수 검증

**M4=2,518개=M3 2,118개+일본 24곳×16개+울란바토르 1곳×16개.** 원본 feature_sets.json의 `local_plus_station_history_all_balanced`를 사용합니다. M3 전체 포함·관측소/Feature 중복 없음·실제 스키마 존재·role=feature를 확인했습니다. Trajectory 입력은 포함하지 않았습니다.

일본 24곳은 12개 현당 2곳이며 기존 2021–22 품질·거리 기준으로 같은 선정 결과가 나오는 것을 확인했습니다. 관측소를 다시 선정하거나 2023/2024 품질로 바꾸지 않았습니다.

일본은 **승인된 README의 시간 구간 끝 시각 해석, 24h→다음날 00시, JST=KST**를 유지했습니다. 원기관 시간 표기의 외부 재확증을 수행했다는 의미는 아닙니다. 울란바토르는 저장된 UTC 시작 시각+1시간=KST 끝 시각 정렬을 확인했습니다.

추가 400개 이력을 2021–23년 8,760개 예측 시점에서 원자료의 정확한 t 이하 시각으로 재계산해 불일치 0을 확인했습니다. 원자료 중복·시간대·정시 시각·flag 정합성과 미래 참조가 없는 이력 계산을 검증했습니다.

공식 검정 집합은 네 모델 대 persistence와 기존·신규 모델 간 모든 쌍, 총 10쌍×4개 Horizon=**40개**를 계산 전에 고정했습니다. 기존 단계의 원본 통계 파일은 보존했고 이번 통합 비교에서만 새 family로 보정했습니다. M4 vs M1/M2도 모두 공식 개선 미충족이며 전체 결과는 직접 비교 CSV에 있습니다.

제곱오차 DM·Bartlett HAC lag=h/3·원래 3시간 격자 유지, 달력 7일(56슬롯) paired 이동 블록 bootstrap 1,000회·seed 0을 공통 채점기 그대로 적용했습니다. 음수 절단 건수는 모든 모델·Horizon에서 0입니다.

## 6. 문제와 제한 사항

학습을 막는 데이터 불일치·시간 누수·필수 입력 오류는 발견하지 않았습니다. 이미 승인된 울란바토르의 큰 검증 공백은 그대로 존재하므로 해당 관측소 효과를 검증 기간에서 안정적으로 분리하기 어렵습니다. 이 때문에 임의 결측 대체·관측소 제외·설정 재탐색은 하지 않았습니다.

M4는 M3보다 모든 Horizon의 RMSE 점 추정이 높았습니다. 6시간·24시간 MAE는 M3보다 소폭 낮아 지표별 변화 방향이 다릅니다. 이는 일본/몽골 정보가 본질적으로 무용하거나 악영향을 준다는 인과 결론을 뜻하지 않습니다.

2023년은 조기 종료와 설정 선택에 사용한 기간으로 통계는 선택 이후 탐색적 검증 결과입니다. 최종 2024 일반화 성능 입증이 아닙니다. 일본 시간 해석과 자료 공개 지연 미재현이라는 승인된 프로젝트 한계도 유지합니다.

## 7. 이후 작업·재현성

**M3T/M4T·TreeSHAP·Adaptive·2024 Test는 실행하지 않았습니다.** 공통 채점용 기존 궤적 방향 조건만 사용했으며 Trajectory 모델은 구현·학습하지 않았습니다.
