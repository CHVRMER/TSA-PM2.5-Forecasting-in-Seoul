# Stage 1 — M1 6시간 구현·학습 완료

실행일: 2026-11-08 KST. 실행 ID: `M1_h6_20261108_174529_127972`.

## 1. 수행한 작업

국내 M1의 6시간 예측을 모듈형 코드로 구현하고 실제 학습했습니다. 기존 `Models/b_lgbm.py`의 명시적 Feature 구성, log1p 타깃, 네 설정 비교, 시드 3개 평균 방식을 참조했습니다. 기존 모델 코드는 수정하거나 실행하지 않았습니다. SHAP·Permutation Importance·다른 모델·다른 Horizon·Adaptive는 실행하지 않았습니다.

## 2. 생성한 파일

- `configs/m1_6h.json`: 입력 목록·분할·시드·학습 설정.
- `src/feature_groups.py`, `src/data_loader.py`: 명시적 목록 검사·선택 분할 로딩·경계 검사.
- `src/train.py`, `src/evaluate.py`: 학습·저장·평가·그래프.
- `src/__init__.py`, `scripts/run_experiments.py`: 모듈 및 M1 전용 실행기.
- `requirements.txt`: 설치된 직접 의존 패키지 버전. 전이 의존성 전체 lock 파일은 아닙니다.
- `.venv/`: 승인되어 설치된 기본 Python 라이브러리를 공유하는 가상환경(`--system-site-packages`).
- `results/M1_h6_20261108_174529_127972/`: 결과·예측·로그·설정·Feature 목록·코드 체크섬·검증 기록·그래프.
- `models/M1_h6_20261108_174529_127972/`: 시드 0/1/2 모델 TXT와 앙상블 manifest. macOS 파일시스템의 대소문자 구분 여부에 따라 기존 `Models/` 아래의 동일한 새 하위 폴더로 보일 수 있습니다. 기존 파일은 덮어쓰지 않았습니다.

## 3. 데이터와 Feature

입력은 `Dataset/Origin_Features_2021_2024_v3`의 특징표이며 `local_plus_station_history_kr` 1,142개만 사용했습니다. 서울 이력·ASOS·달력 70개와 국내 67곳 × 16개 이력입니다. 정답·메타데이터를 입력에 넣지 않았습니다. 결측은 보존하고 LightGBM이 처리했습니다. 실제 0은 결측으로 취급하지 않았습니다.

- 학습: 2021–2022년 적격 5,761행.
- 검증: 2023년 적격 2,530행.
- 검증 예측 파일: 2023년 전체 예측 시점 2,920행을 보존하고 `eligible`로 지표 계산 행을 구분했습니다.
- 타깃: 중구 111121의 정확히 t+6시간 PM2.5, µg/m³.
- 2024년 예측 시점은 로딩·추론·평가에 사용하지 않았습니다. 검증 구간 끝의 비적격 행 2개는 원본 메타데이터상 정답 시각이 2024년에 속할 수 있으며, 이 행의 정답은 학습·설정 선택·평가에서 모두 제외됩니다. 결과 JSON의 `test_2024_loaded_or_predicted=false`는 2024년 예측 시점에 대한 모델 실행이 없다는 의미입니다.

## 5. 성능 및 설정

2023년 검증 결과이며 최종 테스트 성능이 아닙니다.

| 모델 | n | RMSE | MAE |
|---|---:|---:|---:|
| M1 시드 3개 평균 | 2,530 | **8.306379** | **5.179915** |
| 시드 0 | 2,530 | 8.271753 | 5.179446 |
| 시드 1 | 2,530 | 8.389367 | 5.212487 |
| 시드 2 | 2,530 | 8.373870 | 5.243735 |

단위는 µg/m³입니다. 앙상블이 시드 0 단독보다 조금 나빴지만 사전에 정한 시드 평균 결과를 유지했습니다.

현재 농도 y(t)가 있는 **동일한 2,504행**에서 추가 기준선 비교:

| 모델 | RMSE | MAE |
|---|---:|---:|
| M1 | 8.335912 | 5.195219 |
| Persistence: y(t+6)=y(t) | 9.991810 | 6.137380 |

같은 표본에서 RMSE 개선율은 16.5726%입니다. 2,530행 전체 점수와 혼합 비교하지 않습니다. 통계적 유의성 검정은 이번 단계에 수행하지 않았습니다.

선택 설정은 `num_leaves=15`, `feature_fraction=0.5`, **520회 반복**, 시드 0·1·2입니다. 네 설정을 시드 0의 2023년 원 단위 RMSE로 비교했습니다. 각 설정의 조기 종료는 기존 코드와 같이 **log1p 타깃의 L2**를 기준으로 하며, 최대 5,000회·인내 200회입니다. 시드 1·2는 선택된 반복 수로 학습했습니다.

공통 설정: learning_rate=0.03, min_data_in_leaf=50, bagging_fraction=0.8, bagging_freq=1, lambda_l2=1.0. CPU 스레드는 2개이며 deterministic·force_col_wise를 명시했습니다. 요일은 기존 코드와 동일하게 수치형으로 사용했습니다.

## 6. 문제와 제한 사항

- 설정 선택과 조기 종료에 사용한 2023년 점수이므로 선택 편향이 있으며 최종 일반화 성능을 의미하지 않습니다.
- 산점도에서 일부 고농도 표본의 과소 예측이 보입니다. 원인을 확정하거나 결과에 맞춰 설정을 추가 조정하지 않았습니다.
- 자료 공개 지연을 재현하지 않은 과거 데이터 기반 예측력 비교 연구입니다.
- 현재 실행기는 승인된 M1 6시간만 허용합니다. 로더는 다른 Horizon을 지원하지만 추가 학습은 해당 단계 승인 후 확장합니다.
- `.venv`는 설치된 사용자/시스템 패키지를 공유합니다. 다른 컴퓨터에서는 필요한 의존성을 별도로 설치해야 합니다.
