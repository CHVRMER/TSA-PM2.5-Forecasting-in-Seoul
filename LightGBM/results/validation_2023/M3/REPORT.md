# Stage 3 — M3 3/6/12/24시간 완료 보고

**2023년 Validation** 결과입니다. M1·M2 모델을 재학습·재추론하지 않았고, M4·후속 분석·2024 Test는 실행하지 않았습니다.

**핵심 결과:** M3는 persistence 대비 네 Horizon 모두 공식 개선 조건을 충족합니다. 반면 M3−M2와 M3−M1의 공식 개선 조건은 모든 Horizon에서 미충족입니다. M3는 M2보다 3/6/24시간 RMSE가 낮지만 12시간은 소폭 높습니다.

## 1. 수행한 작업

공통 실험 규칙을 유지해 M3의 중국 61곳·M2 포함·시간 정렬·이력·분할을 검증한 뒤 네 Horizon을 순차 학습했습니다. 기존 src/train.py의 공통 학습 함수에서 M3 허용 목록만 추가했으며, 이전 코드와 비교해 학습 알고리즘·설정 선택 절차는 동일함을 확인했습니다. 공통 채점기·로더·Feature 선택 코드는 변경하지 않았습니다.

## 3. 데이터·Feature 검증

**M3=2,118개=M1 1,142개+중국 61곳×16개 이력(976개)**입니다. 원본 feature_sets.json의 `local_plus_station_history_kr_cn`을 그대로 사용했습니다. role=feature, 실제 열 존재, 중복 없음, Trajectory 입력 없음, M1⊆M2⊆M3를 확인했습니다.

중국 61곳은 **실측 48곳+국경 대리 중국 도시 평균 13곳**입니다. M2의 21곳이 모두 포함됩니다. M2보다 추가된 40곳은 나머지 실측 27곳과 대리 도시 13곳이며 입력 증가량은 640개입니다. 목록과 M2 포함 표시는 `china_61_station_manifest.csv`에 저장했습니다. 대리 도시는 개별 실측 관측소가 아니며 근사 좌표를 사용한다는 한계가 있습니다.

2021–23년 8,760개 예측 시점에서 중국 전체 976개 이력을 원자료의 정확한 t 이하 시각으로 재계산하여 불일치 0을 확인했습니다. 중국 CST·KST의 같은 순간 정렬과 중복·flag 정합성을 확인했습니다. 2024년 관측값은 읽지 않았으며, 별도의 파일 무결성 체크섬 I/O는 수행했습니다.

### 검정 집합 및 공통 채점

실행 전 고정한 현재 비교 집합은 세 모델 대 persistence, M2−M1, M3−M2, M3−M1의 6쌍 × 4개 Horizon=**24개**입니다. 이전 단계의 원본 p/판정 파일을 수정하지 않았으며, 이번 통합 비교의 보정 p는 현재 family에 대해 계산했습니다. 향후 최종 시험의 비교 목록을 이번에 임의 확정한 것은 아닙니다.

제곱오차 DM·Bartlett HAC lag=h/3, 실제 3시간 달력 격자 유지, 달력 7일(56슬롯) paired moving-block bootstrap 1,000회·seed 0을 기존 공통 채점기 그대로 적용했습니다. 음수 절단 건수는 모든 모델·Horizon에서 0입니다. 전체 24개 검정은 M1_M2_M3_2023_validation_tests.csv에 있습니다.

## 6. 검증 결과·문제·제한 사항

- 신규 12개 모델 저장 후 재로드 예측 최대 차이 0.
- 178개 기존 결과·모델·설정 파일 SHA256 불변. M1·M2 공통 예측 사본은 원본과 바이트 동일.
- Stage 2와 공통 평가 시점·정답·M1/M2/persistence 예측이 행 단위로 동일하고, 기존 점 지표도 동일.
- 각 eligible_h, 앙상블 평균, 지표 재계산, 공식 판정·Holm, 데이터 버전·공통 출력 검사 통과.
- 공통 채점기 SHA256 불변. 학습 구현의 변경은 M3 허용 목록과 오류 메시지뿐임을 이전 원문 비교로 확인.
- 데이터 불일치·재전처리 필요·시간 누수는 발견하지 않았습니다.
- M3는 M1보다 모든 Horizon의 RMSE 점 추정이 낮지만 공식 직접 개선 조건은 모두 미충족입니다. M2보다 12시간 RMSE가 약 .0101 높습니다. M3의 3/6/12시간 MAE도 M2보다 소폭 높습니다. 결과를 보고 추가 튜닝·입력 변경·편향 보정을 하지 않았습니다.
- 2023년은 설정 선택에도 사용한 기간입니다. 통계는 선택 이후 탐색적 검증 결과이며 최종 2024 일반화 성능 입증으로 해석하지 않습니다.
- 최종확정 자료 공개 지연 미재현·도시 평균 대리 지점이라는 기존 한계는 유지합니다.

## 7. 다음 단계 및 재현성

원래 공통 규칙은 README_EXPERIMENT_RULES.md와 configs/experiment_rules.json의 확정본을 그대로 유지했습니다. 이번 M3 실행 범위와 family는 scope_before_training.json 및 manifest.json에서 관리합니다. M3 코드·설정 해시는 manifest, 환경 버전은 개별 metrics_and_selection.json, 파일 해시는 file_inventory.csv에 있습니다.
