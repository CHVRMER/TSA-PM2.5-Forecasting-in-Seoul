중국 관측 자료 재감사 결과
=========================

이 작업은 읽기 전용 감사입니다. 원자료, 분석값, 파생 특징, 모델을 변경하지 않았습니다.
전후 SHA256은 source_manifest.json에 기록했습니다. 기존 성능의 원인을 자료 품질로
확정하지 않으며, QC 규칙의 효과는 별도 버전 데이터와 동일 실험의 민감도 비교가 필요합니다.

확인 범위
- 중국 기존48개 측정소: 1,683,072행, 현재 F634에48개 모두 포함
- 중국 국경13개 도시평균:455,832행, 현재 F634에13개 모두 포함
- 신규 중국동부30개 도시평균 QC판:1,051,920행, 현재 F634에는16개 포함
- 각 자료의 본기간과 경계버퍼, 원자료 flag와 기존 QC표시
- 서울 정답이나 모델 예측값은 QC 후보 판단에 사용하지 않음

핵심 결과
1. 기존48곳 PM2.5 결측3.0766%, 최대9985,500초과287셀을 재현했습니다.
   3578A의2021-03-15 16:00KST(15:00CST)는PM2.5=9985,PM10=1327입니다.
   보존된 원본CSV에서도 같은 값이며 체크섬이 출처등록부와 일치합니다.
   파싱/CST-KST 변환 때문에 새로 생긴 값이 아닙니다. 전후 시각과 물질 간
   불일치를 고려하면 매우 강한 수동 검토·격리 후보지만, 제공자 정정값은 없습니다.

2. 24개 이상 연속된 동일한 유효 시간값 구간은120개,3741관측시간입니다.
   단,24개 시간값은23시간의 경과시간일 수 있습니다.24시간 이상 경과한 구간에
   한정하면3213관측시간입니다.3741 중3493시간(111구간)은PM2.5=3입니다.
   저농도 반올림·검출한계·공급자 처리 가능성을 배제하지 않고 센서고장으로
   단정하여 모두 삭제해서는 안 됩니다. PM10도 함께 고정된 구간은1개입니다.
   우선 검토 대상:2230A,2021-01-26 08KST~01-28 15KST,PM2.5=48,56관측시간.

3. 2024-02-10의500초과 값은KST일자로105셀,CST일자로94셀입니다.
   2021~2024의 설날4개일자 합계는KST154셀,CST144셀입니다. 날짜 일치만으로
   불꽃놀이 원인을 확정할 수 없습니다. 황사·연무로 보이는 다른 고농도 날짜도
   포함됩니다.500이라는 숫자를 자동 제거 상한으로 사용하지 않았습니다.

4. 기존 신규도시 QC정책을 진단 목적으로48곳에 계산하면27후보가 생깁니다.
   그중7후보는설날4개CST일자에 있습니다. 국경13곳은22후보 중2후보가 해당합니다.
   기존 신규30도시용 정책을 모든 중국 입력에 그대로 적용하는 것은 신중해야 합니다.
   점프 기준만으로 실제 단기간 고농도도 표시될 수 있습니다.

5. PM2.5>PM10는기존48자료에서50746셀입니다. 작은 역전까지 모두 잘못된PM2.5라고
   판단하면 과도하게 자료를 제거합니다. 물질 간 불일치로는 어느 기기의 오류인지
   단정할 수 없습니다. 단발9985와 모든 작은 역전을 같은 수준으로 취급하지 않습니다.

6. 신규동부30도시에는기존QC가이미적용되어있습니다.PM2.5 3셀,PM10 1셀이
   raw와달라지고 flag20으로분리되어있습니다.PM2.5분석최대883,raw최대1689입니다.
   따라서 현재Dataset전체에'이상치처리가전혀없다'는 설명은 정확하지 않습니다.

7. '1시간스파이크71개'는 정의가 제시되지 않아 그대로 검증할 수 없습니다.
   이 감사의 별도 보수적 진단 기준은48자료12후보,국경자료3후보,신규동부자료1후보입니다.
   기준:현재>=100,과거/미래각3시간 중4개이상 유효,현재>5*max(주변중앙값,10),
   바로전·다음시간각각의3배보다큼.미래값은진단에만사용하며운영QC/모델입력에는사용금지.

주요 결과 파일
- china_audit_summary.json:자료별 전체 통계·flag·시간격자·기존QC 재계산
- station_year_quality.csv:측정소·연도별 결측·최댓값
- constant_run_intervals.csv:동일값 구간과PM10 변화
- pm25_gt500_events.csv:500초과 모든 시점과F634 포함 여부
- daily_extreme_counts_cst.csv:중국현지일자별 극단값 수
- existing_causal_qc_policy_review_candidates.csv:기존신규도시정책의 진단 후보
- isolated_spike_review_candidates.csv:미래맥락을쓴 사후진단 후보
- 3578A_9985_source_evidence.json:원본셀·원본CSV SHA256 대조
- 3578A_9985_context.csv:문제관측 전후12시간
- 2230A_constant48_context_all_pollutants.csv:고정값 구간의 여러물질 전후맥락

재실행
python audit_china.py --project-root ".../Revised_Project" --output-root ".../Results/China"
원자료 읽기 권한과pandas,numpy,pyarrow가필요합니다.출력폴더만생성/갱신합니다.
