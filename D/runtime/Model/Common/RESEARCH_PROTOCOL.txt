연구 질문·가설·공통 실험 규약 개정안
2026-11-07 / 농도 예측 중심 / 기존 DCRNN 구조 유지

1. 배경과 연구 목표

국외 오염물질의 물리적 유입이 존재한다는 것과 국외 관측이 국내 관측 위에 새로운 예측 정보를 제공한다는 것은 다른 질문이다.
국내 일부 관측만 넣은 기준선에서 중국 자료가 유용해도, 제외한 국내 중부·남부 관측이 그 정보를 대신할 가능성이 남는다.
따라서 전국 국내 관측을 확보해 국내 기준선을 강화하고, 예측 지평과 수송 조건에 따라 어떤 권역 정보가 여전히 필요한지를 검증한다.
예측 대상은 서울 중구 PM2.5로 유지한다. 전국 자료 확보가 전국 예측 프로젝트로의 변경을 뜻하지 않는다.

핵심 목표: 충분한 국내 관측을 활용한 기준선에서도 원격 관측의 추가 예측 정보가 남는 조건·예측 지평을 확인하고, 경로 정보를 이용하는 방식이 단순한 전체 입력보다 실제로 도움이 되는지 검증한다.
관측소 수 증가, HYSPLIT과 특정 모델의 조합, ablation 횟수 자체를 신규성으로 주장하지 않는다.

2. Research questions

RQ1. 강화된 전국 국내 관측 기준선에서, 어떤 국내·원격 권역의 관측정보가 서울 중구 PM2.5의 3·6·12·24시간 후 농도 예측에 추가 가치를 제공하는가?

RQ1의 가설
H1a. 전국 국내 관측을 품질·중복을 고려해 활용하면 기존 국내 67곳 기준선보다 오차를 줄일 수 있다.
     비교: 동일 모델·같은 학습 격자에서 국내67 입력 대 전국 국내 입력(또는 학습구간에서 정한 선택/권역 요약 입력).
     감소가 없으면 국내 확대의 예측 이득이 제한됐다고 보고한다. 관측 연결률 증가를 정확도 증가로 대체하지 않는다.
H1b. 강화된 국내 기준선 위에서도 일부 원격 권역은 추가 가치를 제공하며, 그 크기는 권역과 예측 지평에 따라 다르다.
     비교: 국내 기준선 대 국내+중국, 이후 일본·몽골·중국 국경 도시 평균을 범위가 명확한 별도 조건으로 추가.
     3<6<12<24시간의 단조 증가나 거리/풍속 이상의 지평에서만 가치가 생긴다는 제약을 두지 않는다.
     이득이 사라지면 이 데이터·모델·기간·지평에서 국내 관측으로 정보가 상당 부분 대체됐다는 제한된 결론을 제시한다.
H1c. 경로별 농도·기상·가용성 정보는 같은 국가 범위의 관측소 이력 위에 추가 예측 가치를 제공할 수 있다.
     비교: KR+CN 관측 이력 대 동일 KR+CN 이력+KR/CN 전용 경로 입력. 일본·몽골을 추가한 all 요약을 혼입하지 않는다.
     경로 입력이 개선하지 못하면 단순 이력으로도 충분하거나 과거 도착 경로의 추가 정보가 제한됐을 가능성을 검토한다.

RQ2. 예측 시점까지 이용할 수 있는 바람·역궤적·관측 가용성 조건에 따라 권역 정보의 추가 가치가 달라지며, 그 조건을 활용한 예측 결합이 전체 입력 및 고정 결합보다 유용한가?

RQ2의 가설
H2a. 중국 관측의 추가 가치는 서쪽 접근 조건에서 상대적으로 크다는 예상이 있다. 다만 다른 방향에서 0이라고 단정하지 않는다.
     지상 바람, 현재 도착 궤적의 과거 위치, 경로 고도의 바람은 각각 다른 조건 변수로 보고한다.
     계절을 나누거나 통제해 계절 분포 차이가 풍향 효과처럼 보이는지 확인한다.
H2b. 조건별 가중 결합은 국내 모델·전체 입력 모델의 고정 가중 결합 및 전체 입력 단독보다 오차를 줄일 수 있다.
     반드시 Full-input, 고정 가중 결합, 단순 규칙 전환을 비교 대상으로 둔다.
     Full-input에도 동일하게 이용 가능한 기상·경로·가용성 정보를 제공해야 한다. 조건별 방식에만 유리한 정보를 주지 않는다.
     2023에서 고른 가중치의 2023 점수는 가중치 적합 성능이며 독립 검증 점수가 아니다.
H2c. 같은 DCRNN 구조에서 궤적 방향 그래프가 거리 또는 궤적 대칭 그래프와 다른 성능을 보일 수 있다.
     방향성 자체의 비교는 궤적 방향 대 그 그래프의 대칭화로 한다. 거리 대 방향은 연결 기준과 방향이 함께 다르므로 효과를 분리해 과장하지 않는다.
     그래프 빈도·게이트·SHAP·가리기 결과를 오염 질량 기여율이나 물리적 인과성으로 해석하지 않는다.

고농도 탐지·경보 서비스·정책 발령 결정은 이번 핵심 RQ에서 보류한다.
고농도 구간의 농도 오차표는 기술적 보조 분석이며 경보 성능의 입증이 아니다.

3. 데이터 범위와 해석

- 전국 국내 원본에서 승인된 도시대기·교외대기·국가배경 관측을 정리한다. 도로변 관측은 데이터 입력에 넣지 않으며 별도 민감도 실험도 이번 범위에 넣지 않는다.
- 전체 승인 관측의 자료는 보존하되, 주 모델 후보는 2021–22 학습구간의 가용성·메타데이터 조건으로 정한다. 예: 학습 결측률 20% 이하의 기존 품질 기준.
- 신설·폐쇄·이전·코드/좌표 변경과 장기 공백을 기록한다. 2023·2024 성능이나 결측률을 보고 관측소를 고르지 않는다.
- 일본 원본 매칭 후보와 모델용 24곳 균형판을 구분한다. 24곳을 도시 평균으로 잘못 설명하지 않는다.
- 중국 국경 대리 13곳은 중국 도시 평균과 근사 좌표이다. 러시아 관측자료나 러시아·몽골의 국가별 배출 기여가 아니다.
- 울란바토르 한 곳은 몽골 전체를 대표하지 않는다. 2023 장기 결측으로 몽골 추가 가치의 검증력이 부족하다는 한계를 별도 보고한다.
- 일본·몽골은 사전에 효과가 0이어야 하는 음성 대조군으로 고정하지 않는다. 조건별 수송과 공통 기상 등으로 예측 정보가 있을 수 있다.
- 현재 도착 궤적의 과거 경로는 입력 가능한 후보지만, 사후 GDAS 분석의 배포 지연까지 재현한 실시간 운영 예보 실험이라고 주장하지 않는다.
- 고정 850 hPa 바람은 현재 기본 데이터에 없다. 경로 1–6시간 구간의 바람을 850 hPa 바람으로 부르지 않는다.
- 500 m AGL은 도착 고도이다. 과거 경로 고도는 변하며 고정 950 hPa나 850 hPa의 대체 관측으로 취급하지 않는다.

4. 입력 조건과 M3T 범위

입력 조건은 데이터셋 이름보다 실제 포함 관측소·국가·열의 allowlist로 정의한다.

D67: 기존 국내 67곳 + 서울 이력·ASOS·달력.
DN: 학습구간에서 정한 전국 국내 후보/권역 요약 + 동일 기본 입력.
DN_CN: DN + 명시한 중국 관측(기존 48곳과 중국 도시 평균 13곳을 구분 기록).
DN_CN_JP, DN_CN_MN 또는 DN_ALL: 일본/몽골 추가 조건을 별도 표시한다. 서로 다른 범위를 모두 M3라고 부르지 않는다.
T_KR_CN: 같은 KR/CN 이력 입력 + KR/CN 전용 경로 특징. 범위가 all인 농도·가용성 요약은 제외한다.
T_ALL: 일본·몽골까지 포함하는 경로 입력. KR/CN 조건과 다른 실험으로 관리한다.

기존 v3 값은 덮어쓰지 않는다. 열 이름을 남겨두고 의미만 바꾸는 것도 금지한다.
M3T 수정은 v3의 all 국가 요약을 KR/CN용 allowlist에서 제거하는 방식이다. 각 열의 실제 참조 관측망 범위를 manifest에 기록한다.
전국 관측소 이력을 새로 추가해도 기존 v3의 KR 경로 요약 참조가 자동으로 전국으로 확대되는 것은 아니다. 새 전국 경로 요약을 재생성할 때는 별도 버전·명칭·출처를 부여한다.

5. 공통 학습·평가

타깃: 중구111121 PM2.5, 정확히 t+3/6/12/24시간 실측. 주평가6시간.
예측시점: KST 3시간 격자. 입력 이력은 시간별 자료.
분할: 2021–22 학습, 2023 설정 선택, 2024 동결 후 재평가. 경계를 넘는 정답은 eligible=False.
모델 입력은 t까지의 자료만 사용하고, 전처리 추정값·노드 선택·그래프 집계는 학습구간으로 한정한다.
모델별 결측 대체와 정규화는 학습 자료로만 적합하며, 정답은 보간하지 않는다.
학습 빈도·평가 행·loss 공간·재변환·튜닝 예산을 실험별 manifest에 기록한다.
같은 질문을 비교할 때 입력 범위와 평가 행을 같게 한다. 서로 다른 아키텍처 비교를 특정 그래프 효과로 설명하지 않는다.

고정 eligible 행 수(3/6/12/24시간 순)
train:      5,762 / 5,761 / 5,759 / 5,755
validation: 2,531 / 2,530 / 2,528 / 2,524
test:       2,874 / 2,873 / 2,871 / 2,867
이는 기존 타깃과 분할 규칙으로 확인한 값이다. 신규 모델의 결측·실패로 줄이지 않는다.

Persistence: t 실측, 결측이면 t 이전 마지막 유효 관측. Seasonal naive: t+h−24 실측, 결측이면 해당 시점 이전 마지막 유효 관측.
과거 실측이 전혀 없을 때만 훈련 log1p 평균 역변환으로 최후 fallback. fallback 건수·종류·관측 경과시간을 기록한다.
음수 예측은 모든 모델에 동일하게 0으로 자르고 개수를 기록한다.

시드별 성능: 각 시드를 같은 행에서 개별 채점하고 점수 평균·표준편차를 보고한다.
예측 앙상블: 같은 입력·모델·데이터버전의 시드별 µg/m³ 예측을 산술평균해 별도로 채점한다.
시드별 점수 평균은 앙상블 점수가 아니다. 시드 수를 표본 수에 곱하지 않는다.

RMSE·MAE 필수, MBE·R²·Persistence 대비 개선률 보조.
DM은 제곱오차, Bartlett HAC 지연 기본 max(h/3−1,0), 실제 달력 지연을 유지한다.
7일 블록 bootstrap은 실제 56개 3시간 슬롯을 재표집하고 결측 기간을 압축하지 않는다.
한 실행에서 선언한 모든 지평·비교의 p값에 Holm을 적용한다. RMSE 차이 구간 상한<0과 보정p<0.05를 함께 보고한다.
통계적 유의성과 함께 개선의 크기·기간·조건별 안정성을 보고하며, 작거나 음수인 효과도 그대로 제시한다.

6. DCRNN 보존과 별도 실험

기존 구현을 유지한다: 시간별48시간 입력, DCGRU 인코더, 24단계 자가회귀 디코더, teacher forcing 없음.
정답 감독은 3·6·12·24시간 네 지평만 사용한다. 다른 노드 미래값이나 중간24시간 정답을 입력하지 않는다.
hidden32, 확산2단계, encoder/decoder1층 등 기존 구조를 유지하며 hyperparameter 변경은 별도 experiment_id로 관리한다.
그래프 세 가지: 거리 / 2021–22 궤적 방향 / 해당 방향 그래프의 대칭화.
거리 sigma는 기존 기준값182.34497839213313km, cutoff500km로 고정한다. 노드 추가 때 sigma를 다시 추정해 함께 바꾸지 않는다.
궤적 그래프는 최근접 후보 하나, 과거→현재 방문 순서, 같은 경로의 같은 방향 간선 중복 제거, 최대 공백6시간 규칙을 유지한다.
노드 확장: legacy116 → v3균형판154 → 전국 국내 확장 노드 구성은 서로 다른 입력범위 실험이다.
노드 확장에 따른 인접행렬 차원·정규화 결과는 바뀔 수 있으나, 이를 아키텍처 변경이나 새 그래프 알고리즘으로 혼합하지 않는다.
팀원 direct-head 프로토타입으로 교체하지 않고, 원래 AR 디코더를 유지한다.

7. 검증 이력과 결론의 범위

2024년 기존 DCRNN 결과와 전체 기간 지도는 이미 확인했다. 새 입력·설계로 얻은 2024년 점수는 재평가/추가 실험이며 완전히 보지 않은 최초 시험으로 설명하지 않는다.
설계·선택은 2021–22/2023에서 동결하고 그 이후의 변경 이력을 남긴다. 향후 독립 기간이 확보되면 별도의 외부 검증으로 구분한다.
이번 업데이트는 데이터 정리·품질·추가 연결률·실행 가능한 모델/채점 연결을 제공하며, 모든 후보 모델의 전체 GPU 재학습까지 수행했다는 뜻이 아니다.
추가 연결률은 가용 관측의 기하학적·시간적 연결이다. 이것만으로 예측 성능 증가·국가별 질량 기여·인과성·새 알고리즘의 novelty를 주장하지 않는다.

8. 현재 구현의 국내 입력 참고조건
전국 자료573곳(중구포함)과 외부572곳은 데이터 보존 범위이며, 신규505곳 전체 이력8080열을 sidecar로 보존한다.
공통 loader의 초기 비교 참고조건은 훈련80% 관측 기준 신규447곳으로 설정해 DCRNN national_v3(601노드)의 국내 정보 범위와 맞췄다. 전체505곳을 사용하면 additional_set과 input_condition을 명시해 별도 입력범위 실험으로 관리한다.
기존67곳은 원형 비교를 위해 그대로 유지하며 그중 일부가 새 품질참고 기준을 충족하지 않아도 원래 입력을 조용히 삭제하지 않는다.

9. 원형 그래프의 몽골 평가 제한
울란바토르 노드는 현재 원형 세 그래프에서 서울에 도달하지 못한다. 원형 DCRNN은 서울 노드만 읽고 전역 node pooling을 하지 않으므로 이 노드의 무효과는 구조상 제약이다. DCRNN의 몽골 무효과를 자료의 정보 부재로 해석하지 않으며, 그래프 무관 모델에서의 평가와 구분한다. 이를 바꾸기 위한 임의 간선·새 readout은 별도 모델/그래프 실험으로 관리한다.
