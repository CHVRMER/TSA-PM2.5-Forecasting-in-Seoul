# M1 공통 출력·채점 보완 보고

2026-11-08. 기존 모델과 예측을 재사용했으며 학습·추론을 다시 수행하지 않았습니다.

## 1. 수행 작업

기존 M1의 저장된 2023년 예측을 공통 5열로 내보내고 .meta.json을 추가했습니다. RMSE·MAE·MBE·persistence 대비 개선률·Bartlett HAC DM·7일 블록 bootstrap·Holm·조건별 채점을 추가했습니다. 기존 score.py는 원문을 보존하고 새 공통 채점 실행기로 교체했습니다.

## 2. 생성·수정 파일

- `Models/predictions/M1.parquet`, `M1.meta.json`: 공통 예측과 데이터 버전·시드·설정·학습 기간·모델 해시.
- `src/common_scoring.py`: 새 공통 채점 모듈.
- `Models/score.py`: 새 실행기. 원문은 `Models/score_legacy_20261108.py`에 그대로 보존했습니다. 보존본은 감사용이며 실행에는 새 score.py를 사용합니다.
- `src/data_loader.py`: 적격 정답만 별도로 읽어 검증 경계의 2024 정답 읽기를 차단했습니다.
- `src/train.py`: 향후 승인된 학습 실행에도 공통 출력+sidecar를 만들도록 연결했습니다. 승인된 score.py 변경은 보존본 해시로 확인하며 기존 데이터 해시 검사는 유지합니다. 이번에 이 학습 함수를 실행하지 않았습니다.
- `scripts/complete_m1_outputs.py`: 저장된 예측을 내보내는 일회성 보완 실행기. 기존 출력이 있으면 덮어쓰기를 거부합니다.
- `scripts/check_common_scoring.py`: 실제 시험 자료 없이 HAC·Holm·접근 차단·1회 잠금을 확인하는 테스트.
- `results/common_scores/validation_20261108_180908_443529/`: 보완된 검증 결과. 기존 Stage 1 결과 파일과 모델은 모두 보존했습니다.

## 3. 사용 데이터

2023년 M1 6시간 저장 예측을 재사용했습니다. 명시적 1,142개 Feature로 이미 학습된 모델이며, 이번 작업은 새 Feature 선택이나 모델 튜닝을 포함하지 않습니다. 검증 대상 정답은 v3에서 `origin_split=validation AND eligible_h6=True` 조건으로만 읽었습니다. 공통 평가 행은 M1과 persistence 모두 유한한 2,504개입니다.

## 4. 2021–22 / 2023 / 2024 준수 검토

- 보존된 M1 실행 코드·설정·로그에서 학습 입력은 2021–22, 조기 종료와 소규모 설정 선택은 2023입니다.
- 설정별 학습과 추가 시드 학습 모두 2021–22 표본만 사용했습니다. 2023년을 학습에 추가하는 최종 재학습은 없었습니다.
- 현재 보존된 M1 기록에는 2024 성능을 계산한 시험 실행·결과가 없습니다. 기존 baseline 파일에 2024 예측이 있다는 사실은 M1 시험을 수행했다는 의미가 아닙니다.
- 이전 M1 검증 예측에는 정답 시각이 2024년인 경계 2행이 진단 열에 있었지만 모두 비적격이어서 학습·설정 선택·지표 계산에 사용되지 않았습니다. 공통 예측 파일은 정답 열 자체를 포함하지 않습니다.
- 이번에는 2024 시험을 새로 수행하거나 재시험하지 않았습니다. 잘못된 M1 시험 기록이 없는 상태에서 시험을 실행하면 최종 1회 평가를 불필요하게 소비하기 때문입니다. 과거 외부에서 실행 후 삭제된 기록까지 없었다고 보증하는 것은 아닙니다.

## 6. 시간축과 통계 처리

DM은 전체 2023년 3시간 격자 2,920슬롯을 보존합니다. 공통 평가 행의 제곱오차 차이에서 관측 평균을 빼고, 누락 슬롯의 영향량을 0으로 둡니다. 실제 k×3시간 떨어진 슬롯에만 Bartlett 가중치 `1-k/(lag+1)`를 적용하며 `lag=h/3`입니다. 평균 차이의 분산 분모는 공통 관측 수의 제곱입니다. 결측 없는 경우 기존 식과 일치함을 검사했습니다. 정답이나 예측값을 0으로 대체한 것이 아닙니다.

Bootstrap은 압축된 관측 56행이 아니라 **전체 격자의 연속 56슬롯(168시간)**을 이동 블록으로 재표집합니다. 모든 모델·기준선에 같은 블록을 적용하고 누락 슬롯도 함께 옮긴 뒤, 해당 반복에서 유효한 공통 행으로 점수를 계산합니다. 반복 1,000회, 시드 0입니다. 56개 시각의 첫 점과 끝 점 차이는 165시간이고 각 슬롯이 3시간을 대표하므로 블록 길이는 168시간입니다. 이번 유효 반복은 1,000회이며 공통 표본 수의 반복별 범위도 결과에 저장했습니다.

이 방식은 시간축 압축 문제를 고친 것이며, 긴 결측 구간 자체를 복원하지는 않습니다. 시간 의존성과 결측 구조에 대한 bootstrap/HAC의 근사적 해석 한계는 유지됩니다.

Holm 비교 family와 판정식은 계산 전에 `policy.meta.json`에 저장했습니다. 최종 행 기록의 sidecar에는 데이터 버전·모델별 시드·설정·체크섬이 함께 있습니다. 채점 이후 예측 폴더 지정 옵션 및 학습 출력 연결만 보완했으며 현재 코드 해시는 `checks.json`에 추가 기록했습니다.

## 7. 시험 잠금과 검증

새 score.py는 `--final` 없이 test를 요청하면 Parquet를 읽기 전에 중단합니다. `--final`에 더해 다음 동결 manifest가 필요합니다.

- `models`: 한 번에 평가할 전체 모델 목록.
- `horizons`: 한 번에 평가할 전체 Horizon 목록.
- `no_refit_on_2023: true`.
- `artifacts_sha256`: 시험 예측·모델·설정·sidecar 등 동결 산출물의 프로젝트 상대 경로와 SHA256. 모든 비교 모델의 시험 예측 파일은 필수입니다.

시험 읽기 전 프로젝트 공통 `results/final_test_2024.lock`을 배타적으로 생성하므로 같은 프로젝트에서 2회 실행을 거부합니다. 실패해도 잠금을 자동 해제하지 않습니다. 필요 시 사용자가 실패 원인과 이미 노출된 결과를 검토하고 별도 재시험을 승인해야 합니다. 이번에는 실제 잠금을 소비하지 않았습니다.

검증은 규칙적·불규칙 결측 격자의 HAC 수동 계산 비교, Holm 예제, Parquet 접근 이전 시험 거부, 임시 파일의 1회 잠금, 기존 모델·원본 결과 불변, 적격 정답 불변·경계 정답 차단, 공통 예측의 원래 앙상블 예측과의 일치를 확인했습니다. 모델 재학습·추론은 수행하지 않았습니다.

검증 채점만 다시 수행하는 명령(새 결과 폴더를 만듦):

```bash
.venv/bin/python Models/score.py --split validation --models M1 --horizons 6
```

새 학습 실행의 결과 폴더 안 `M1.parquet`를 사용할 때는 `--prediction-dir <결과폴더>`를 지정할 수 있습니다. 데이터 버전이 다른 모델은 동일 비교에 섞지 않아야 합니다. 아직 학습하지 않은 3/12/24시간 결과는 그래프에 채워 넣지 않았습니다.
