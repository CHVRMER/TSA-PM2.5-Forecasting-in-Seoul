# Graph WaveNet: 완료된 24시간 실험과 H48 준비 코드

이 폴더는 **실제로 완료된 3·6·12·24시간 예측 실험**의 결과와 재현용 그림을 공유한다. 최신 36·48시간 확장 코드는 별도 버전이며, 아래 결과가 그 코드의 학습 성능을 의미하지 않는다.

중간발표의 주 비교는 **2023 validation**이다. **2024 test는 이미 확인한 예비 평가 결과**로 구분한다. 검증·시험 연도가 다른 모델의 RMSE를 직접 나란히 놓아 우열을 판단하지 않는다.

|---|---|---|

| 시간 수용영역 | RF13 | RF61 |
| 최대 epoch / patience | 50 / 10 | 75 / 10 |
| 학습률 조절 | 없음 | ReduceLROnPlateau |

| 파라미터 수 | 339,832 | 511,186 |
| 결과 상태 | 여섯 조건의 학습·추론·공통 채점 완료 | CPU 소형 수치 검사·재개 검사 등을 수행한 준비 코드. 실제 GPU full 성능 결과는 이 폴더에 없음 |

## 입력 조건이 뜻하는 것

| 조건 | 사용할 수 있는 외부 PM2.5 관측 계열 | 추가 궤적 요약 |
|---|---|---|
| M1 | 국내 514 | 없음 |
| M2 | 국내 514 + 가까운 중국 21 | 없음 |
| M3 | 국내 514 + 중국 77 | 없음 |
| M4 | M3 + 일본 42 + 몽골 1 | 없음 |
| M3T | M3와 동일 | 국내·중국으로 제한한 218개 |
| M4T | M4와 동일 | 허용 전체 국가 322개 |

전체 외부 계열은 **634개**, 중구 정답 노드까지 **635노드**다. 일본 동부18·중국 동부16이 추가되기 전의 F600이나 후보 합집합 일본40·58개와 혼동하지 않는다.

모든 조건에 동일한 635노드와 고정 거리 그래프를 유지한다. 제외 관측값은 정규화 전에 가리고, 해당 노드는 잠재 중계 노드로 남긴다. 따라서 M1의 ‘국내만’은 **국내 PM 관측 입력만 사용한다는 의미**다. 학습형 adjacency는 학습되는 연결이며, 시각별 바람에 따라 자동 갱신되는 수송 경로나 물리적인 국가별 오염 기여율이 아니다.

## 결과에서 알 수 있는 것

2023 validation RMSE, 단위 µg/m³. 아래 수치는 표시를 위해 반올림했으며 그림은 원래 정밀도를 사용한다.

| 조건 | 3h | 6h | 12h | 24h |
|---|---:|---:|---:|---:|
| M1 | 5.978 | 8.189 | 10.689 | 12.324 |
| M2 | 6.069 | 8.144 | 10.683 | 12.616 |
| M3 | 6.027 | 8.077 | 10.474 | 12.501 |
| M4 | 5.840 | 8.141 | 10.729 | 12.404 |
| M3T | 6.281 | 8.597 | 10.888 | 12.292 |
| M4T | 6.716 | 8.726 | 10.818 | 12.260 |

- 국내 관측만으로도 경쟁력 있는 기준선을 형성한다. 최저 RMSE 조건이 예측시간과 연도에 따라 달라지므로 특정 국외 지역의 안정적인 추가 가치를 단정할 수 없다.
- 원래 사전 입력 비교는 **6대비×4지평=24개**, 기준선 비교까지 포함한 **Holm52 가족**을 사용한다. 2023과2024 모두 이 24개 입력 비교에서 유의한 개선은 없었다. 2023에서는 M4T가 M4보다 3h에서, 2024에서는 M2가 M1보다 6h에서 유의하게 악화했다.
- 2024의 M3T는 M3보다 12·24h RMSE가 수치상 낮지만 보정 후 유의하지 않다. ‘유의하지 않음’은 효과가 정확히0이거나 동등하다는 증거가 아니다.
- 단일 시드의 달력 블록 bootstrap은 학습 초기화에 따른 변동을 대신하지 않는다. 소수 조건의 추가 시드, 시간 수용영역, 궤적 변수 선택을 검증 구간에서 나누어 비교하는 것이 후속 과제다.
- 상세 보고서의 GWN 대 DCRNN 비교는 **이전 불안정 DCRNN 실행과의 역사적 비교**다. 최신 DCRNN H48보다 GWN이 우수하다는 결론으로 사용하지 않는다.

## 그림만 다시 만들기

원자료·모델 가중치·원본 ZIP·개인 Windows 경로가 필요 없다. 이 폴더에 복사된 두 지표 CSV만 읽는다.

```bash
python -m pip install numpy pandas matplotlib
python Codes/plot_shared_results.py --validate-only
python Codes/plot_shared_results.py
```

기본 실행은 `figures/Run_<한국시각>_<고유번호>/`에 PNG·SVG·PDF와 검증 manifest를 새로 저장한다. 기존 그림을 덮어쓰지 않는다.

저장소에 처음 배포할 고정 그림을 생성하는 경우에만, **비어 있는** 출력 폴더를 명시할 수 있다.

```bash
python Codes/plot_shared_results.py --output-dir figures
```

폴더에 이미 파일이 있으면 중단한다. 기존 자료를 지우지 말고 기본 명령으로 새 실행 폴더를 사용한다. 스크립트는 모델을 학습하거나 통계 검정을 다시 계산하지 않으며, 입력 CSV가 실행 중 바뀌지 않았는지 검사한다.

`legacy24_review/Codes`는 당시 ZIP·개인 경로를 사용한 역사적 감사 코드다. 현재의 휴대 가능한 그림 재생성은 **`Codes/plot_shared_results.py`**를 사용한다. 원시 예측을 통한 통계 검정 재현에는 별도 원본 자료가 추가로 필요할 수 있다.
