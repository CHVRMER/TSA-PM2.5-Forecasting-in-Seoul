이번 단계는 외부822개 후보입니다. 국내572(기존67+전국추가505), 중국61(측정소48+러시아·몽골 국경 근처 중국 도시 평균13), 일본 서부188, 몽골1이며 서울 중구는 별도 별표입니다. 국내는 도시533·교외28·국가배경도서11이고 도로변은 포함하지 않았습니다. 일본 서부188개는 당시의 전체 후보이며, 이후의25개 재선정을 앞당겨 적용하지 않았습니다.

첨부 원본 그림은 v5 선정 후693개 후보와, 배경으로 흐리게 그린 제외 일본163개를 보여줍니다. 그693개가 현재 모델 입력 전체는 아닙니다. 최근 주 실험은 외부634개+중구=635노드입니다. 국내 품질선정과 일본 서부 선정이 달라졌으며, 일본25와 현재24는 같은 집합에서 단순히 하나만 뺀 관계도 아닙니다.

- 중국의 망사 영역은 주로 산둥 남부·장쑤·안후이·저장 북부를 포함하는 기존 `China_East` 선정 영역입니다. 행정구역 경계가 아닙니다.
- 일본의 망사 영역은 기존 `Japan_East`/혼슈 일본해측 선정 영역입니다. 당시 추가18개는 도쿄도 측정소가 아니라 나가노·교토·기후·후쿠이·도야마·야마가타·니가타·아키타의 지점입니다.
- 두 경계 모두 원본 손그림 다각형 좌표를 그대로 사용했습니다.

## 궤적과 재현

원본과 같은 경도100–145°, 위도25–55°, 육지/바다색·마커를 사용했습니다. 궤적은2021–2024년 매월 첫 도착시점부터 같은 간격으로4개씩 고른192개이며,500m AGL 도착·과거0–48시간입니다. 기존 전국 지도에서 사용한 ‘월 중간 사분위’ 규칙과 구분해 첨부 원본 코드의 표본 규칙을 재현했습니다. 두 그림은 같은822개 후보와 같은192개 궤적을 사용합니다. 궤적은 공기 이동의 모형 결과이며 오염원·국가별 배출 기여율이 아닙니다.

`Results/plotted_candidates_822.csv`, `display_trajectory_sample.parquet`, `planned_region_boundaries.geojson`과 `Codes/assets/countries.geojson`으로 전체 원자료 없이 다시 그릴 수 있습니다. Git Bash에서 다음과 같이 실행하면 매번 새 Replot 폴더에 저장합니다.

```bash
python Codes/plot_station_stages.py
```

위 명령은 이 폴더를 현재 위치로 사용할 때의 예시입니다. 기존 결과가 있는 위치를 직접 출력 경로로 지정하면 덮어쓰지 않고 중단합니다. 원본 Dataset·HYSPLIT·모델·첨부 그림과 기존 결과는 변경하지 않았습니다.
