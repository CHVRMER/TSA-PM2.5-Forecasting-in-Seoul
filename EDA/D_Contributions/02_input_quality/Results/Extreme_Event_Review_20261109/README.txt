오류 의심 극단값의 시각·위치·사건 검토 (2026-11-09)

데이터를 수정하지 않았습니다. 원자료에 기록된 사실, 공식적으로 확인된 대기 사건,
그리고 아직 검증하지 못한 원인 가설을 구분합니다.

가장 중요한 판단
탕산 3578A의 PM2.5=9,985는 실제 황사 사건 중 발생한 매우 큰 관측 불일치입니다.
황사가 있었다는 사실만으로 이 개별 PM2.5 값을 유효한 관측이라고 인정할 수 없습니다.
반면 울진 PM2.5=803은 같은 날짜·시각·수치를 명시한 원논문이 있어 산불 신호라는 근거가 강합니다.

대상 5건 (농도 단위 ug/m3, 중국시간 CST / 한국시간 KST)
1) 3578A: 허베이성 탕산시 政府服务中心, 39.66941N 118.24498E.
   2021-03-15 15:00 CST / 16:00 KST. PM2.5=9,985, PM10=1,327.
   PM2.5는 직전191 -> 9,985 -> 다음시간 결측 -> 그다음61.
   원본 보관 CSV에도 같은 값이 있어 프로젝트의 파싱/시차변환이 만든 값은 아닙니다.
   현재 분석 입력에 남아 있습니다. 기기 상태·단위·전송 오류 원인은 미확정입니다.
   좌표는 기록된 측정소 메타데이터이며 2021년 이전/이전 이력까지 독립 인증한 것은 아닙니다.
2) 장쑤성 롄윈강 도시평균: 2021-03-15 19:00 CST / 20:00 KST.
   PM2.5=1,500, PM10=102. PM2.5는 87 -> 1,500 -> 84.
3) 산둥성 린이 도시평균: 2021-03-17 16:00 CST / 17:00 KST.
   PM2.5=1,451, PM10=153. PM2.5는 29 -> 1,451 -> 27.
4) 장쑤성 옌청 도시평균: 2021-03-23 16:00 CST / 17:00 KST.
   PM2.5=1,689, PM10=1,721. 각각 24 -> 1,689 -> 37 / 65 -> 1,721 -> 77.
   두 물질이 함께 오르므로 1~3과 동일한 오류 확신도로 다루면 안 됩니다.
   매우 강한 국지적 연소 플룸 또는 데이터 전달/집계 오류가 가설이나, 정확한 사건 근거 미확보입니다.
   도시평균이므로 단일 측정소 근처의 국지적 플룸만으로 도시 전체 평균을 설명하기도 어렵습니다.
5) 장쑤성 난징 도시평균: 2021-12-07 19:00 CST / 20:00 KST.
   이것은 PM2.5가 아니라 PM10=9,211 사례입니다. PM2.5=82, 다음시간 PM10=132.
   앞선2시간은 결측입니다. 해당시각 이 값을 검증할 공식 먼지 사건 자료는 확보하지 못했습니다.

2~5는 기존 QC에서 이미 flag20으로 격리됐고 원값이 별도 열에 보존돼 있습니다.
이 값들이 현재 분석값으로 남아 있다고 해석하면 안 됩니다.
도시평균의 지도 좌표는 시청 부근 근사값이며 특정 센서의 위치가 아닙니다.

당시 황사 확인
중국 생태환경부 2021-03-15 발표는 몽골 중동부에서 발생한 먼지가 중국 북부로 이동했다고 설명합니다.
같은날09시 베이징 PM10=6,450, PM2.5=462, 중심6구 PM10=8,108을 보고합니다.
이는 실제 고농도 배경의 증거이며 탕산 3578A 개별 PM2.5=9,985의 검증은 아닙니다.
PM2.5와 PM10은 입경 범위가 포함관계입니다. 독립 계측기 오차로 작은 역전은 가능하지만,
7.5배 역전과 고립 급등을 황사만으로 설명할 근거는 부족합니다.
전송/소수점/단위/항목 혼동, 기기 입경분리·유량·필터 부하 문제, PM10 과소측정 등은
가능성일 뿐이며 기종·원시 상태코드·검교정/운영 로그가 없어 어느 원인인지 확정할 수 없습니다.
9,985를 무조건 결측 코드나 기기 상한이라고 단정할 근거도 없습니다.
